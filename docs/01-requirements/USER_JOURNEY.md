# SARIRA — User Journey

**Status:** Phase 0 baseline

## Tujuan

Menjelaskan pengalaman end-to-end dari orientasi hingga adaptasi program, termasuk kebutuhan emosi, risiko, dan respons sistem.

## Journey Inti

| Tahap | Tujuan pengguna | Tindakan | Output SARIRA | Risiko/pagar |
|---|---|---|---|---|
| Kenal | memahami manfaat dan batas | membaca onboarding | positioning, non-diagnosis, data yang dibutuhkan | jangan menjanjikan hasil |
| Akses | membuat akun aman | login/registrasi | sesi dan recovery | usia/identitas tidak pasti |

## Journey per Segmen

### Teen

Momen kritis: undangan dan consent wali, bahasa tidak menghakimi, privasi diary, larangan janji tinggi, serta screening risiko. Keberhasilan bukan penurunan berat/tinggi, melainkan pemahaman pola dan action aman sesuai usia.

### Dewasa

Momen kritis: target berat yang realistis, alergi/pantangan, mode makanan yang sesuai biaya/waktu, dan fleksibilitas ketika rutinitas berubah. Growth request dialihkan secara jelas ke fungsi/postur.

### Healthy Aging

Momen kritis: onboarding sederhana, fallback manual, dukungan pendamping, keterbacaan, safety jatuh, dan menghindari target makan yang berisiko kehilangan massa/fungsi.

### Orang Tua dengan Profil Anak

Momen kritis: hubungan berwenang, teknik pengukuran, tren bukan single point, riwayat sakit/Posyandu, dan referral. Sistem mengedukasi tanpa label stunting otomatis.

## Moments of Truth

1. **Consent minor:** pengguna harus tahu siapa melihat apa.
2. **Safety merah:** referral harus lebih jelas daripada fitur lain dan tidak tertutup gamification.
3. **Data tidak cukup:** pengguna merasa dipandu, bukan disalahkan.
4. **Pattern Map:** alasan dapat dipahami dan angka confidence tidak menyesatkan.
5. **Menu swap:** alternatif benar-benar sesuai alergi, budget, dan equivalence rule.
6. **Correction:** data yang salah dapat diperbaiki dan hasil berubah secara transparan.

## Acceptance Criteria

- Setiap persona dapat menyelesaikan happy path dan menemukan jalur keluar/referral.
- Remaja/wali dapat menjelaskan permission masing-masing setelah onboarding.
- Pengguna dapat membedakan hasil sementara, final baseline, dan diagnosis.
- Pengguna yang menolak wearable tetap mencapai baseline melalui input manual.
- Pengguna dapat menyebutkan alasan Weekly Action serta cara menggantinya.

## Validasi

Uji journey terpisah untuk remaja+wali, dewasa berbagai literasi, orang tua/pengasuh anak, lansia mandiri, lansia+pendamping, serta pengguna dengan data/izin terbatas.
