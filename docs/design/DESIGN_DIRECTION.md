# SARIRA Active Balance — Design Direction

**Versi:** 0.1 · **Status:** Phase 1 coded prototype · **Dasar:** seluruh keputusan Phase 0

## Tujuan Arah

SARIRA Active Balance membuat produk terasa aktif dan premium tanpa berubah menjadi aplikasi gym. Visual mendukung nutrisi, aktivitas ringan, pertumbuhan keluarga, kebiasaan, pencernaan, dan healthy aging untuk usia 12–75 tahun.

## Karakter

- Bersih, modern, aktif, sehat, ramah, dan premium.
- Tidak klinis, tidak menghakimi, dan tidak bergender kuat.
- White space lega, tipografi hitam tegas, card membulat, serta lime sebagai aksen terbatas.
- Hero memakai bentuk abstrak keseimbangan dan aktivitas; tidak memakai standar tubuh ideal.
- Hierarki selalu menempatkan safety dan satu Weekly Action di atas engagement.

## Hubungan dengan Referensi Visual

Yang diadaptasi: latar bersih, card besar, tombol mudah dijangkau, floating bottom navigation, progress ring sederhana, kategori pastel, dan hierarki langsung terlihat.

Yang tidak disalin: komposisi layar, foto, branding, ikon, nama menu, warna identik, struktur konten, serta tubuh berotot sebagai identitas utama.

## Ekspresi Visual

| Area | Ekspresi |
|---|---|
| Brand | Primary Dark + Lime, bentuk organik yang bergerak seimbang |
| Weekly Action | Card gelap, satu fokus, progress lime, dua aksi jelas |
| Baseline | Soft Lime, progres 14 hari, tanpa streak menghukum |
| Nutrition | Mint/cream, tipe minimum/range/maximum tertulis |
| Activity | Dark + pastel blue/mint, visual gerak abstrak beragam |
| Safety | Status teks, ikon, penjelasan, dan next step; warna hanya pendukung |
| Family/Aging | Kepadatan rendah, konteks profil aktif, mode lansia |

## Guard Desain

Jika pertimbangan visual bertentangan dengan Phase 0, urutan resolusinya adalah safety → product requirements → functional requirements → user flow → acceptance criteria → estetika. Lime tidak boleh menurunkan keterbacaan, referral tidak boleh tersamarkan, dan `unknown` tidak boleh terlihat seperti hijau.
