# Design Principles

## DP-01 — Safety is the visual priority

Red referral menggantikan action terkait, yellow menampilkan pembatasan, dan unknown meminta data/next step. Acknowledgement tidak mengubah status.

## DP-02 — One explainable priority

Beranda menampilkan maksimal satu Weekly Action utama. Pola pendukung tidak berubah menjadi daftar tuntutan.

## DP-03 — Insufficient is a useful state

UI menjelaskan data yang kurang, alasan dibutuhkan, serta cara melengkapi, melanjutkan, atau keluar tanpa kesimpulan.

## DP-04 — User agency is visible

Pengguna dapat kembali, menyimpan sebagian, mengoreksi, menerima, menunda, mengganti dengan alternatif setara, memakai input manual, dan mencabut izin.

## DP-05 — Age and role shape the experience

Profil aktif selalu terlihat. Remaja memakai consent wali + assent, orang tua memakai konteks relationship, dan healthy aging menawarkan mode lansia serta pendamping granular.

## DP-06 — Numbers disclose their meaning

Nutrisi selalu menampilkan angka, satuan, periode, tipe target, status teks, target/batas, sisa, dan limitation. Data/Rule/Evidence confidence tidak digabung menjadi health score.

## DP-07 — Neutral language over judgment

Pola dijelaskan sebagai “tercatat”, “berada dalam rentang”, “mendekati batas”, atau “masih perlu dilengkapi”; bukan “gagal”, “buruk”, atau “tidak disiplin”.

## DP-08 — Simulations are explicit

Mock authentication, AI, scan, camera, wearable, safety rule, formula, dataset, dan referral registry diberi label Simulasi/Mock Data di konteks penggunaannya.

## DP-09 — Responsive means recomposed

Mobile satu kolom + floating nav; tablet memakai navigation rail + dua kolom; desktop memakai sidebar permanen + dua/tiga kolom dan content width terbatas.

## DP-10 — Accessible by default

Target minimum 44×44, focus state, keyboard order, screen-reader label, text scaling, status bukan warna saja, reduced motion, dan dekorasi dikeluarkan dari accessibility tree.
