# Mock vs Real

## Real pada Phase 4

- Authentication/session dan seluruh onboarding Phase 3.
- Starter Journey context dan baseline create/resume.
- Day index, lifecycle, progress kalender, dan perjalanan 14 hari.
- Daily check-in serta draft/retry lokal.
- Meal, sleep, activity, manual steps, optional body, dan digestive logs.
- Daily tasks, daily/overall completeness, history correction.
- Day 7 checkpoint/feedback dan Day 14 readiness/extension foundation.
- Consent enforcement, profile ownership, audit, PostgreSQL persistence.

Label **Demo** dihapus dari kemampuan tersebut. Source manual tetap ditampilkan agar tidak disalahartikan sebagai wearable data.

## Tetap Demo/belum production

- Final Pattern Map dan causal pattern.
- Weekly Action decision engine.
- Nutrition Engine, calorie/macro/micronutrient calculation, Guided Meal recommendation, Flex Kitchen calculation.
- AI/LLM, RAG, citation retrieval production, AI insight.
- Food photo/barcode recognition.
- HealthKit, Health Connect, smartwatch/wearable sync.
- Motion Coach/pose estimation.
- Growth, Family Growth, Healthy Aging recommendation engine, digestive diagnosis.
- Payment, billing, marketplace, dan food ordering.

Home dan Progress menampilkan capability yang belum aktif dalam card terpisah dengan badge **Demo** serta copy bahwa hasil belum dihitung. Data real tidak dicampur ke angka mock. Screen inventory juga tidak lagi melabeli login, registration, daily check-in, atau digestive logging dasar sebagai simulasi.

## Development configuration

Safety rules Phase 3 dan completeness/readiness Phase 4 adalah rule nyata yang berjalan, tetapi content/threshold masih berstatus development dan membutuhkan product/expert validation. Status tersebut berbeda dari mock: input/output tersimpan dan deterministik, tetapi belum disetujui sebagai clinical/product production policy.
