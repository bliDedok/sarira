# Weekly Action Library

Library `weekly-action-dev-v1` memiliki satu action development per domain:

| Code | Domain | Action | Target |
|---|---|---|---|
| `ACT-PORTION-CHECKIN-001` | Portion | Periksa rasa lapar dan kenyang | 4/7 hari |
| `ACT-SUGARY-DRINK-001` | Sugary/energy dense | Catat pilihan minuman | 4/7 hari |
| `ACT-SLEEP-ROUTINE-001` | Sleep | Jaga waktu mulai istirahat | 4/7 malam |
| `ACT-LIGHT-ACTIVITY-001` | Activity | Tambahkan aktivitas ringan | 4/7 hari |
| `ACT-CONTEXT-CHECKIN-001` | Contextual eating | Catat konteks sebelum makan | 4/7 hari |
| `ACT-PROTEIN-BREAKFAST-001` | Meal balance | Tambahkan sumber protein saat sarapan | 4/7 hari |

Definition menyimpan usia eligible, safety restrictions, required evidence, actionability, active state, validation label, dan exact version. Activity dan protein-breakfast diblokir untuk safety `RED`. Semua item adalah development content yang membutuhkan expert/product validation.
