# Six Pattern Domains

| Domain | Feature utama | Makna terbatas |
|---|---|---|
| `PORTION_INTAKE` | energy range, hunger, fullness, skipped meals | sinyal konsistensi porsi/asupan |
| `SUGARY_ENERGY_DENSE` | sugary drinks, sugar-limit frequency | sinyal pilihan manis/padat energi |
| `SLEEP` | duration, duration/timing variance, perceived quality | sinyal rutinitas tidur |
| `ACTIVITY_SEDENTARY` | active days/minutes, steps, low-activity days | sinyal aktivitas tercatat |
| `CONTEXTUAL_EATING` | mood-meal co-occurrence, hunger, fullness | association kontekstual non-kausal |
| `MEAL_BALANCE_REGULARITY` | breakfast, meal regularity, protein/fiber/balance | sinyal keteraturan/keseimbangan makan |

Nutrition dan Guided Meal/Flex Kitchen menjadi evidence bagi domain yang sudah ada; keduanya tidak membuat domain ketujuh. Body/digestive data tetap dapat disimpan dari fase terdahulu, tetapi Phase 7 tidak membuat diagnosis, intoleransi, atau hubungan sebab-akibat.
