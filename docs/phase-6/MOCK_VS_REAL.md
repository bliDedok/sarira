# Mock vs Real

Mock repository dan Prisma repository memakai kontrak/service/engine yang sama. Keduanya menyediakan recipes, policy, plans, replacement, cooking, consumption, personal recipes, dan ownership. Mock dipakai untuk test cepat; PostgreSQL membuktikan migration, transaction, constraints, dan persistence.

Real pada Phase 6: model/version/snapshot, Phase 5 calculation, remaining, eligibility, score, alternatives, consumption, Flex preview, substitution foundation, personal history, API, dan UI.

Masih synthetic/development: 15 food fixtures Phase 5, 8 recipes, policy weights, suggestion thresholds, estimated cost, cooking steps, equipment, dan content wording. Tidak ada AI tersembunyi atau fallback calculator.
